
## Iris gear feasibility (2026-10-27)
- Records: items $19C–$1A4 are 13-byte key-item records (flags $20, slot 00, mask 0, no words). Bank $96 has no free space; reclaim by sharing identical records (Door key…Ancient key: 20 × 13-byte identical records → ~247 bytes; l2mod already uses Key26–30, so the Iris patch must not touch those). Item flag byte b0: bit3 = cursed, bit5 = important (Dual blade has bit5 and is equippable, so Iris can keep bit5 = not sellable).
- Female-only: equip mask $12 (Selan $02 + Tia $10).
- Stat funnel: PartyStatTotals $81:F4ED (char record at $C1): maxHP +$25 = base +$51 + equip +$74; maxMP +$27 = +$53 + +$76; STR/AGL/INT/GUT/MGR from +$55..+$5D + equip +$7C..+$84 + secondary +$8A..+$92; AGL capped $C7. Called after equip changes (PartyRebuildAllEquipmentStats $82:994E), level-up (PartyApplyLevel $81:F7E6) and equipment preview (PartyStatTotalsOfCopy on a $7E:3800 copy). Level = +$0E; equipment = 6 words at +$66 (id & $1FF). One hook here gives level scaling + set bonus everywhere.
- Ancient Cave: AncientCaveEnter $84:878A moves inventory/equipped items found in the blue-item table $94:EEA0 (41 words, CPX #$0052 at $84:887F and $84:8B07) to $7F:BF00, snapshots state to $7F:B000, resets the party, re-adds the saved items (normal mode). AncientCaveExit $84:890B: Iris items in INVENTORY only (list $91:FFCA) → carry list + event flag $C8+k; blue items in inventory and equipped slots (+$66, chars $0C13.. step $BE) → carry list; state restored; carry list re-added. Defeat ($84:8B9C) sets mode $FF → only the pre-cave blue items come back. So: Iris carry-in = add the 9 ids to a relocated blue table; must dedupe on exit (Iris loop + blue loop), and equipped Iris would be lost on exit in vanilla.
- New Game+: $0B51 = title choice (bit7 loaded game; low bits 0 START, 1 RETRY (EXP/gold ×4 at $81:DA06), 2 GIFT (cave mode, starts map $68)). RETRY starts a brand-new game: nothing carries over. SRAM is 8 KB = 4 files × $800, all used; $70:0000 bits 0–1 last file, bit2 game cleared, bit3 cleared in RETRY (set in ending $8E:B2EE). Carry-over idea: on a RETRY start, LoadGameFile(last file) into live state, harvest Iris ids, then run the normal new-game init and give them back (+ set flags $C8+k so the cave doesn't spawn duplicates).
- Gruberik collector (map $69) takes each Iris item with op_25 → must become display-only for wearable Iris.

## Dialogue editing (v1.1, 2026-10-27)
- tools/scriptasm.py = scene-script assembler (inverse of scriptdec): labels/gotos relative to the map block base, text compression via dictionary DP; `far_window()` for far text. mods/gruberik_dialogue.py writes collector.asm + collector_far.asm; mods/decomp_map.py decompiles one map from any ROM (L2ROM env).
- Text back-reference `0A lo hi`: copy length is counted in text-engine steps, not bytes. All 285 vanilla references cover plain ASCII only; a reference containing $05/$06 dictionary pairs printed garbage in snes9x. The assembler only references plain ASCII.
- Dictionary words print through a one-level return slot ($1252/$1254, op $00 returns), so nothing that prints a dictionary word can nest inside another such call.
- New script op $02 "far text" (`02 lo hi bank`, $80:FC20): plain ASCII + $03 + $0C–$0F, $00-terminated, same return slot. TextMeasure hook at $80:C68B measures it. Strings live in bank $80 free space ($80:FC20–FF9F, ~560 bytes used). Expanding the ROM to 3 MB and reading far text from $D0:8000 did NOT work in the snes9x core (wrong bytes read), so the expansion was dropped.
- Map $69: talk $58 = treasure hunter, $59 = collector; script region $8A:F026–$8A:F422 (talk $5A starts at $8A:F423). Vars: $0E = gallery count; $1E free (no vanilla script uses it). If-term $10 = var ==, $12 = var >=, flags test with $01 negate / $40 OR / $80 AND; $20/$30 = goto if true/false. Unused event flags: $DC–$EF, $F3–$F9 (plus a few low ones). $DC = "party member wears the Iris set", maintained by the stat hook.
- In-game testing trick: the real collector isn't present in an early-game save, so a test ROM points NPC talk ids $50/$51 at the new scripts; RAM pokes set flags ($0797 = flags $C8–$CF) and var $0E ($07AC). Event flag n = $077E + n>>3, bit n&7.
- Saves for testing can be made in the interpreter (SaveGameFile with $05AC set to the target map) and loaded in snes9x.
